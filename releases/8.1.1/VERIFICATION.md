# ZenFlow Vision 8.1.1 — исправление речи

`node --test tests/*.test.mjs`: **113 passed, 0 failed**. Node.js 22+; зависимости не нужны.

101 предыдущий сценарий проверен на новом выпуске. Добавлены 12 проверок: подтверждение старта/завершения, поздняя загрузка русского голоса, resume для paused, not-allowed, таймаут запуска, нулевая громкость/нет API, запоздалый callback, удаление события только после onstart, событие при выключенной речи, зависший native speaking, тихий Pomodoro, восстановление после audio-busy.

Воспроизведена ошибка логики прежней реализации: извлечение события из очереди происходило до проверки возможности озвучки. Интерфейс считал голос включённым до получения подтверждения запуска. Причина отсутствия физического звука на устройстве пользователя неизвестна.

Тесты используют имитированный речевой API и DOM. Они не проверяют динамик, Bluetooth, системную громкость, качество детекции или ограничения конкретного браузера. Для проверки на устройстве нажмите «Включить голос и проверить», дождитесь тестовой фразы и поднесите ёмкость; при ошибке статус покажет причину или таймаут.

Вызов speak ставит фразу в нативную очередь; подтверждение запуска обрабатывается отдельно. [MDN speak](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/speak). Ошибки поступают через error и показываются пользователю. [MDN error](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance/error_event).
