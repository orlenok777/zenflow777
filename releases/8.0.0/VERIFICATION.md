# ZenFlow Vision 8.0.0 — функции и проверка

Дата: 2026-09-06. Команда: `node --test tests/*.test.mjs`. Результат: **84 passed, 0 failed**. Требуется Node.js 22 или новее, зависимостей для тестов нет.

## Покрытие

21 проверка чистых алгоритмов; 31 параметризованная проверка управления датчиками (выключение, ожидание, ошибка, восстановление); запуск приложения с 27 встроенными самотестами; 28 интеграционных сценариев; 3 проверки целостности выпуска. Общие тесты управления проверяют изоляцию и состояния, а не точность каждой модели.

Интеграционные сценарии: вода/отмена/восстановление, кофеин/настроение, повреждение хранения, конкурирующая вкладка, валидация импорта, Pomodoro, автопереход, отсутствие/зависание камеры, улыбка, калибровка, несколько лиц, ожидание рук, телефон, невидимые суставы, дыхание/отдых глаз, отсрочка, освобождение треков, отсутствие API, поздний stream, ошибка одной модели, запись/лимит/неподдерживаемый API, настройки камеры, экспорт, звук/переключение, очередь уведомлений.

Тестовый DOM не выполняет раскладку CSS. MediaRecorder, Web Audio и ответы моделей имитируются; физическая камера и реальный микрофон не используются. Требуется отдельная ручная проверка на целевом устройстве.

## Проверка на своей камере

1. Откройте приложение по HTTPS, нажмите «Проверить все функции», затем включите камеру и дождитесь моделей.
2. Сядьте перед камерой и выполните калибровку; проверьте отключение/включение модулей и возврат после исчезновения лица.
3. Для скелета отойдите так, чтобы суставы были видны. Начните разминку; неполное движение не должно давать приседание.
4. Проверьте запись короткого видео, скачивание и остановку камеры.
5. Проверьте таймер, запись воды, перезагрузку страницы и восстановление данных.

## Что не измеряется

Пульс, диагнозы, личность, эмоции, объём выпитой воды и расстояние в сантиметрах не выводятся из видео. Коэффициенты модели и геометрические эвристики зависят от света, ракурса, окклюзий и качества камеры. Частота моргания может недооцениваться при низкой частоте обработки.
