# ZenFlow Vision 8.1.2 — записанные голосовые сообщения

`node --test tests/*.test.mjs`: **123 passed, 0 failed**.

Сохранены 113 проверок 8.1.1. Десять новых тестов проверяют путь MP3 без SpeechSynthesis, разные файлы для бутылки/стакана, подтверждение через playing, отказ autoplay, загрузку/таймаут, поздний reject предыдущего play(), неизвестную фразу, карту записей, контрольные суммы всех файлов и интеграцию очереди приложения с плеером.

Десять WAV синтезированы локально eSpeak NG 1.51 (ru, speed 155), проверены на ненулевой RMS и длительность >0.3 секунд. Затем преобразованы FFmpeg в MP3 mono 44.1 kHz 96 kbps с нормализацией loudnorm I=-16, TP=-1.5. SHA-256 и исходный текст сохранены в audio/manifest.json. Исполняемые файлы синтезатора не входят в сайт; публикуются только звуковые записи. Источник синтезатора: https://github.com/espeak-ng/espeak-ng.

Проверка через имитацию HTMLMediaElement не измеряет физический динамик, системную громкость, Bluetooth или разрешения браузера пользователя. Причина повторного отсутствия звука остаётся неизвестной; MP3 обеспечивает отдельный путь, который пользователь может проверить нативной кнопкой ▶ и прямой ссылкой.

HTMLMediaElement.play может быть отклонён браузером; интерфейс показывает отказ и предлагает явное нажатие воспроизведения. [Документация MDN](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/play).
